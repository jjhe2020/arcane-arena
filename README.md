# 技能小乱斗

使用 TypeScript + Vite + Three.js 制作的单机网页自动战斗游戏。视觉采用正顶视二维序列帧，玩法以 Ability Arena 为参考，支持桌面与手机横屏。

当前阶段：功能开发，已建立可运行的单机对局和资源接入；逐技能机制及5B还原仍在扩展、验证中，不能视作全量终验完成。

本机开发：`npm install` 后运行 `npm run dev`，打开 `http://localhost:5173`。

构建：`npm run build`。双击根目录 `启动游戏.cmd` 可启动构建后的版本；默认地址为 `http://localhost:4173`。手机横屏可使用本机的局域网IP及相同端口访问。

平衡配置：编辑 `config/` 下的技能、单位和经济 Excel，手动执行 `npm run config:compile` 后再构建；`npm run config:check` 检查是否忘记编译。主技能按 1/2/3/6/9 点逐档成行，所有参数为单数字。操作说明见 [Excel 配置](docs/configuration.md)。

战斗统计：右侧统计面板可展开单位、技能和召唤物，查看伤害、承伤、治疗及护盾吸收；物理、魔法、纯粹伤害分别着色。转身与普通移动按模拟时钟执行，闪烁等明确技能位移保留独立规则。

操作：新技能购买后进入暂存区；满暂存不能购买新技能，同名技能仍可原位升级。点击已有技能再点击目标槽位移动/互换；跨英雄或移入暂存花1金币，暂存装备免费。同英雄内排序免费。选中技能可出售；右键或长按查看说明。大招图标内有特殊边框，商店黄色外框表示已拥有。英雄等级随回合增长，AI资源倍率可选1.0至2.5，每0.1一档。拖动英雄调整下轮阵位，暗色区域不可布阵。开战平滑扩大镜头、移除暗区并淡入敌方后再推进战斗；观战对象始终从下半场视角入场，胜者循环庆祝。地图逻辑尺寸为原来的80%，英雄及特效相对地图放大约25%；射手射程7、法师5.5。备战无时限，准备后自动战斗，空格暂停。手机阵容、商店可横向滑动，也可切换全屏观战。

每局从230项技能抽取100项；图鉴可切换本局与完整目录。商店五级开放4／6／6／8／10个商品，3级起开放终极技能；另外两格为God占位。层数跟随技能实例转移。对局自动保存在本浏览器；权限被阻止时可继续本次游玩并手动重试保存，损坏或不兼容的旧档会保留备份。

验证：`npm test` 包含经济/库存、英雄成长、战斗时序与恢复、230项目录执行稳定性及难度整局测试；构建后运行 `node scripts/serve.mjs`、`node scripts/browser-smoke.mjs` 、`node scripts/sidebar-layout-smoke.mjs`、`node scripts/battle-presentation-smoke.mjs` 和 `node scripts/shop-menu-smoke.mjs` 验证生产版本操作、图标、等级、16档难度和比例布局。其余手机、故障恢复及高负载脚本见`scripts/`。构建前会自动刷新机制覆盖报告。目录稳定性测试不证明每项技能机制已与原作逐项核验。

原作逐项验收正在持续进行：运行 `npm run reference:verify`，按实际来源和具名结果测试更新[230项状态](docs/skill-reference-status.md)。[验收规则](docs/reference-acceptance.md)说明版本依据、Super/Gaben来源和完整放行条件；开发中的r6检查点不代表230项已全部通过。

图片库包含约373MB桌面图集和186MB移动图集，按设备、技能和动作加载，不会开局一次下载全部图片。移动档保留全部动画帧；纹理缓存会释放不再使用的图集。素材导入说明见 `public/data/README.md`，美术母版保留在独立来源项目。
