# v0.1.1-r7：商店识别、暂存购买与回合等级

本开发版本以 C16 源码检查点 `224ba7f6a3a5755b6228ddce33f4d5f7185629d7` 为基线，落实六项补充需求及用户确认的 1A、2C。保留 AA 数值、Super/Gaben、四职业、平面竞技场和已确认自定义。

## 本次行为

- 商店移除右上角 i 按钮，保留右键及移动端长按说明。触摸长按与鼠标悬停使用独立计时器，避免混合输入设备取消长按。
- 全部 75 个已登记大招图标生成独立 SVG 资源，其中 62 个为主技能、13 个为授予技能。原始图像像素嵌入不变，紫金边框位于图标内部；商店、技能槽、图鉴共用同一资产。
- 商店对自己已装备或暂存的同名技能显示黄色外框。观战他人时仍按自己的库存判断，出售最后一个实例后高亮消失。
- 新技能购买后先进入暂存；暂存满时原子拒购，不扣钱、不消耗商品或库存。同名技能按用户确认的 2C 原位自动升级，可绕过满暂存；保留原实例与永久奖励，9 点仍拒购。AI 同样先暂存，再通过免费合法装备操作整理构筑。
- 第 N 回合英雄为 N 级，后到场英雄直接使用当前等级。当前实战快照等级锁定，下轮布阵显示下轮等级。一级完整总值只包含一次基础属性，后续属性成长与永久奖励分别增加；真实幻象和职业克隆继承等级攻速，普通召唤物保持独立原生模板。
- AI 每轮金币倍率提供 1.0–2.5、每 0.1 一档的 16 个选择；新局、存档、界面共用同一有效档位集合。整局验证覆盖 1、1.5、2、2.5 四个代表档位。
