# 数值配置盘点

运行 `node scripts/audit-configurables.mjs` 生成源码数字盘点和直接参数候选。报告记录当前机械配置 hash、每个源码文件的数字及配置读取数量、已开放字段，以及仍需逐机制判断的参数位置。候选不是已确认缺陷，不能批量替换后宣称原生行为一致。

| 分类 | 可编辑位置 | 生效方式 |
| --- | --- | --- |
| 职业完整一级属性、成长、攻击时序与距离 | 单位配置／职业 | 实战和布阵详情共用 |
| 召唤物身体属性、攻击类型及倍率 | 单位配置／召唤单位 | 模板生成与召唤 |
| 属性换算、移速攻速边界、基础恢复、通用战斗默认 | 单位配置／底层规则 | 全局战斗规则 |
| 技能前后摇、距离、冷却、魔耗、效果数字及机制系数 | 技能配置／技能等级、授予技能等级、扩展参数 | 1/2/3/6/9档和授予技能原生等级 |
| 技能说明、Buff名称与说明、状态归并和生命周期展示 | 技能配置／技能资料、状态资料 | 界面展示；来源技能ID和枚举编译时验证 |
| 价格、收入、库存、商店等级及英雄到场轮次 | 经济配置 | 玩家与AI共用真实交易 |
| 时限、护甲系数、基础攻速、施法缓冲及默认攻击前摇 | 全局配置／战斗规则 | 战斗结算与布阵属性预览 |
| 棋盘尺寸、布阵边界、默认出生站位 | 全局配置／棋盘布阵 | 逻辑地图与渲染投影共用 |
| 购买、重复升级、职业匹配、空槽与商店升级权重 | 全局配置／AI策略 | AI经济决策 |
| 平板双排阈值、字号、触摸尺寸、血条及Buff尺寸 | 全局配置／界面表现 | 仅展示，单独计算展示hash |

本轮新增62项全局字段并继续迁移13个实际生效的技能参数，保留迁移前默认值。补接原表中已存在但被最终覆盖实现忽略的狂战士之血力量奖励及时间漫游短期闪避参数。原三份工作簿的既有单元格经过独立读取逐格对比，新增状态资料和参数之外的业务内容没有改变。距离换算规范化至15位有效数字，避免Excel导出后的二进制浮点尾差改变原棋盘边界。

直接调用剩余数字逐项归为状态标记、攻击类型枚举、强制移动锁、刷新租约、动画播放或已被最终实现覆盖的旧代码。每条保留依据记录在盘点报告；旧代码对应的有效生命、伤害、范围、时长和系数在最终实现中读取表值。明确表示整场的旧120秒常量改为共用战斗时限，调长战斗后不会让这些永久状态在第120秒提前消失。

固定容量、模拟步长、RNG、结算顺序、索引、精度容差和安全上限继续保留在代码。技能机制中的光环刷新租约、永久状态哨兵、特殊触发节拍等必须结合实际结算判断；历史常数提取档案不能作为当前有效配置批量导入。每个技能专属可调数字继续归其技能参数，不能在全局表另留一份副本。
