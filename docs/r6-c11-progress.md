## 实际修复

- **Overcharge / Cask**：过载增益跟随真实 Tether 连接与断开，避免同一受益者重复获得增益，恢复按受益者当前最大生命值计算。疯狂生长区分可见性、魔免与持续控制分量；自然之握采用分段生成、激活、伤害及残留时钟。超负荷分别保留AA攻击减速1.2秒和历史移动减速0.8秒，使用实际施法执行信息积攒充能，区分物品、零冷却和无施法触发的动作；命中时先施加主目标减速，再结算爆发和主攻击，反弹保留初始主攻击快照。超强力量按攻击点消费次数，未命中也消费；Gaben 碎颅击为非暴击、非分裂的物理条件附伤，仍共享一次格挡及普通吸血。麻痹药剂采用真实首发与反弹弹体、命中处抵挡、随机后续目标和共享计数；诅咒刷新保留最初生命快照和原有周期，不重新起算损血基数。
- **Phantom / Ward**：幻象在创建和初始化前声明强幻象身份，补齐生命与魔法创建快照；原生等级保持独立域。幻影突袭采用具名跳变及相邻落点，Gaben 匕首经过真实攻击分量协议。相位转移按实际引导生命周期处理隐藏、无敌和升级攻击。枪魂在变身阶段锁定动作，结束后进入攻击伤害转换与物理保护；Gunslinger 区分普通攻击点和技能额外攻击，避免递归触发。瘟疫守卫在冻结落点创建原生身体，继承在初始化前降至基础 AA 被动档；使用独立弹速、攻击时序、恢复与穿刺攻击类别，英雄、普通单位和强化护甲目标分别取配置倍率。
- **Plasma / Pulse**：等离子场以 636 原生速度向外、向内扫过，中心跟随施法者，两方向各命中一次；两次减速有独立时长，未被显形的隐形单位不受影响。Super 半径取最终 1100，不重复叠加升级数值；Gaben 最大伤害不再错误地强制最大减速。毒性攻击在同次主伤害之前施加叠层、减抗及 Gaben 减甲；魔免或守卫未获得毒素层时不产生空偷抗，持续伤害保留既有首跳时钟。强攻 AI 选择最近且生命低于 80% 的友方，执行顺序为增益、强驱散、免疫。原始咆哮区分主目标穿透魔免与次要目标不穿透，主目标先晕后伤，次要目标先伤后控制；侧推为 450 距离、1 秒连续运动，完全共线时只禁用不侧移，驱散推移状态会停止对应控制器。脉冲新星开启即刻造成伤害，1 秒后才开始维持耗蓝；真实关闭不再重复消耗开启费用。恶魔赦令以原生四级纯粹伤害从第 0 秒起产生 40 次爆炸，最后一次为 9.75 秒；独立施放、尸体来源延续及 Gaben 每目标完整伤害均有具名结果。

## 共享能力

- 开关关闭使用独立执行入口，绕过开启状态的冷却锁和蓝量门槛，保留硬控制、动作锁与技能禁令。关闭不改写另一项攻击前摇或引导的截止时间、普通攻击时钟和面向；固定关闭冷却可在重置后重新启动，并校验真实技能对象，旧来源不能写入替换后的槽位。关闭事件的通用施法钩子策略仍按下面的来源边界记录。
- 攻击记录显式区分普通攻击和技能产生的额外攻击。固定附伤进入暴击前快照一次；条件附伤按调用方声明决定是否随攻击比例缩放。标记为不参与分裂的类型分量只从分裂基数中排除，保留其自身伤害、格挡及恢复语义。
- 召唤创建支持初始落点、创建前强幻象身份和复制 AA 等级上限。原生技能等级在自己的域内保留。瘟疫守卫穿刺倍率从单位表读取，未在运行代码中复制第二套数值。
- 实际法术执行信息包含施法者、物品资格、消耗与冷却，可供附近友军观察者使用；未把所有 cast 展示事件当成一次正常法术执行。
- 跟随中的世界效果读取身体的插值展示位置。等离子场出入环、战吼方向特效和新星脉冲均来自真实发生记录；图集寿命只控制展示，不增加伤害、随机数或战斗时钟。赦令使用已导入的新星命中特效回退，不声称新增了专属爆炸美术。

## 留存边界

本批 15 项的来源、版本冲突和具体组合仍逐条记账，不能把有限结果描述为完整原作终验。

- **Plasma / Pulse**：等离子环宽与身体半径边缘、Gaben 外推时长和距离函数、施法者死亡后的结算与展示规则仍有工作候选。偷抗的名义系数、达到叠层上限后的计数、驱散和死亡生命周期尚缺原始 AA 实现依据；正向偷抗计数及 Time Lock / Array 调用组合也保留具名结果缺口。战吼反射属于实际共用机制缺失，次要目标的精确几何、状态抗性与障碍组合另列。新星关闭钩子和输入禁令、无目标时的自动关闭、赦令 10 秒重放及偷取技能失效生命周期尚未全部证实。
- **Phantom / Ward**：AA“所有友军”与原生英雄体资格、幻象各被动和形态继承例外、匕首授予等级和落点策略、其余未具名攻击修饰组合、相位转移特殊物品动作及失去偷取槽后的引导规则，均保持精确边界。枪魂的 AA 类别与历史不可驱散效果存在冲突；Gunslinger 幻象资格、任意职业身体的额外射程及变身跨发射／命中时点尚未全部闭合。瘟疫守卫手动攻击指令和完整被动继承资格仍不由基础被动绿测代替。
- **Overcharge / Cask**：Super 受益者在施法者死亡后的完整资格、任意来源刷新优先级、AA 超负荷反弹传播全部充能的原始语义、碎颅击叠加与 Break / Mute 资格、末次超强力量消耗后的精确动画、药剂目标死亡或隐形后的后续弹道及诅咒等级和应用顺序，继续按组账本记录。自然之握的树木增幅等环境分支需要相应场景模型和直接来源，不能由平面藤蔓结果扩证。

非数值机制以实际读取的 Wiki 和历史版本核对；AA category 标签不单独证明自定义运行规则。已明确的 AA 数值、Super/Gaben 和自定义效果继续保留。树木、视野、高低地及未具名复现的其它组合仍按各自范围记录。
