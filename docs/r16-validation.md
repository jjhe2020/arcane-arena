# r16 技能实验场

## 使用方式

- 在游戏的“对局菜单”打开“技能实验场”。本地生产构建也可直接访问 [技能实验场第 1 页](http://localhost:4173/skill-lab.html?page=1)，使用上一页、下一页或页码选择浏览全部图鉴。
- 230 项可装备技能按图鉴顺序分为 23 页。每页 10 项，每项并排显示 3 点基础、6 点 Super、9 点 Gaben，共 690 个独立场景。窄屏把同一技能的三个点数档纵向排列，各木桩的伤害栏始终在演示右侧。
- 本页各场使用同一播放时钟，可暂停、重播或切换 0.5×、1×、2×。页面复用本游戏的战斗结算、角色动画及特效图集。滚出视口的场景继续结算，滚入视口后恢复绘制。

## 实验口径

- 每场一名只装备待测技能的英雄与三个三角形排列的训练木桩。英雄固定 12 级，同技能三档共用职业和随机种子。少数需要近战的技能使用近战英雄。木桩基准为 10,000 生命、5 护甲、25% 魔抗，自身保持待机。
- 主动技能将最近的 ① 作为唯一初始敌方瞄准目标，点目标取其位置，自身范围技能在可用半径边缘开场。弹射、穿透、溅射、召唤及强制位移仍按技能本身结算。木桩死亡后可重新站起，累计伤害继续记录。
- 右侧显示战斗账本记录的逐木桩累计实际伤害，技能及其派生来源与普攻分列。技能强化直接并入普攻伤害包时，账本将其归入普攻列。桌面悬停数值可查看物理、魔法、纯粹拆分。
- 每场使用 30 秒观察窗，主动技能成功施放一次后观察其后续效果。长持续技能和召唤物按观察窗采样。部分技能需要低生命等前置状态，场景注明对应初始布置。需要额外施法者、其他技能或木桩主动攻击的机制，显示其触发条件，伤害依场内实际结果记录。

## 验证记录

- 全部 690 场均完成 30 秒引擎遍历，直接敌方单位和点目标施法均以 ① 为初始瞄准目标。定向引擎测试覆盖同档可重复、固定靶位、边缘施法、斩杀和木桩复原。
- 生产版实验场冒烟逐页检查了 23 页，覆盖桌面、390px 窄屏、暂停与重播、服务工作线程下的分页、实际画布和特效图集。魔法箭 3／6 点的技能伤害分别为 270／345，仅命中 ①。9 点按机制弹射，三个木桩各承伤 345。3 点刺针扫射在范围边缘只命中 ①，实际伤害 65.4。
- `npm test` 通过 4,106 项测试，`npm run reference:verify` 通过 3,457 项，`npm run build`、生产资源校验、浏览器冒烟、桌面和手机战斗展示、录像回归及 PWA 离线检查均通过。施法距离专项探测了 1,395 条等级记录，配置接线审计通过。
