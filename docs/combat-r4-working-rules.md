# r4 动作时钟与概率工作规则

这些实现用于补齐可执行机制，不能证明与未知补丁版本的 Ability Arena 完全一致。

## 动作时钟

`attackTimePct` 控制攻击前摇与下一次攻击的剩余时间；普通攻速、基础攻击间隔和目标限定攻速变化也按重新计算的攻击间隔与前摇分别保留剩余进度；`castTimePct` 控制施法前摇和后摇。进入或离开减速状态时，按新旧倍率之比换算尚未完成的动作，不重置已经完成的进度。时间结界的 `-550%` 延续项目公开解释：动作时间变为 6.5 倍。

引导时长、持续区域脉冲、技能冷却与投射物飞行使用世界时间，不乘施法动画倍率。原英文写的是 movement / attack / cast speed，未写延长 channel duration，因此当前不擅自增加引导时长。这是需要原作对照的语义选择，不能将“引导没有拉长”重新归为无实现。

持续场控制可标记 `ignoreStatusResistance`，避免 0.15 秒轮询标记被高状态抗性缩成小于轮询间隔而漏出行动。时间结界的离场短暂余留仍为项目工作值。

## 可检验的 PRD

不替换通用 `random()`。只有显式调用 `chance(probability, triggerKey)` 且列于 `PRD_WORKING_ELIGIBILITY` 的触发使用 PRD；选随机目标、随机角度、浮动伤害值和其他未指定触发仍用原来的种子均匀随机。

第 n 次连续尝试的成功概率为 `min(1, C × n)`。成功后 n 回到 1；失败后加一。以生存概率之和计算预期等待次数，再二分求 C，使长期成功率等于技能给定概率。例如 25% 的系数约为 0.08474409，不把 0.25 直接作为累积步长。当前白名单全部使用数学校准路径；低于 0.001% 的异常外部输入采用稀有事件渐近式，目录触发没有使用该路径。

当前明确选择的工作白名单：

| 技能 | 独立触发键 | 资格 |
|---|---|---|
| 恩赐解脱 | critical | 当前实现中的成功攻击修饰判定 |
| 勇气之霎 | defensiveCounterattack、offensiveCounterattack | 原有两套内部冷却分别允许时 |
| 集中火力附带雷锤 | maelstrom | 原有内部冷却和攻击条件允许时 |
| 超强力量附带重击 | bash | Gaben 且原有重击冷却允许时 |

没有把鱼人守卫的固定次数重击改为概率触发，也没有将所有暴击、闪避或自定义升级擅自归入 PRD。这四项资格是公开的项目选择，尚无对应 AA 补丁的原生程序证明。

计数按战斗单位、技能实例/临时槽、触发键隔离；两个同名技能、不同召唤物和偷取槽不会共享失败数。首次从零失败开始，概率变化时清空失败数。单位死亡不清空，整场新战斗清空，不作为跨回合能力 charges。存档以输入和固定步重放恢复相同计数。

`tests/combat-clock-prd.test.ts` 验证校准方程、失败上界、成功重置、10 万次长期频率、概率变化、实例隔离、存档恢复以及速度变化中的未完动作。上述测试是实现校验，不是原作对战验收。

## 攻击快照与几何

`baseAttackDamage` 是命中时、目标防御结算前的有效基础攻击快照，包含当前加法/百分比攻击增益与调用方倍率，但不含随后执行的暴击/攻击修饰。`attackDamage` 则包含这些修饰。二者均不使用目标扣血量反推，避免把目标护甲或护盾再次带入弹射。

召唤物可声明 `attackMin` / `attackMax`，每击以种子连续均匀抽样相对区间中值的偏移，再应用现有攻击增益。未声明区间的职业身体维持原有固定基础值。连续抽样而非整数取样仍须原作对照。

Empower 锥形采用固定历史候选 `cleave_starting_width=150`、`cleave_ending_width=360`、`cleave_distance=650`：从攻击者沿主目标方向测量，宽度按半宽/半径线性增加，不额外加单位碰撞半径。AA Super 的“+200 cleave radius”暂解释为终点半宽增加 200，不同时扩大距离；这是公开的几何解释。

无敌斩每个固定步以有效攻击间隔更新斩击进度，包括自身加法 40 攻速及其他状态/属性攻速；原来的“用基础间隔一次预排全部斩击”已移除。起手先攻击原目标，随后按当前位置筛选 375 范围内可单体选中的敌人，使用有种子的随机选择；无目标时结束，不会在目标重新出现后继续旧排程。加法攻速、立即首击与一个固定步内终止是可测试的工作语义，仍待对应 AA 版本对照。

## 纯表现来源

授予子技能保留真实 `skill` 与 `points`，并额外快照 `visualSkill` / `visualPoints`。弹体、区域、状态、施法/命中/治疗事件分别携带这两组身份：子技能有自己的图集时使用自身等级，缺少时才由渲染层回退父技能升级图集。父技能或临时槽消失后，已释放效果的来源仍保留；这些字段不参与伤害或随机数。

反击螺旋仅在概率成功且内部冷却允许时发布 `helix` 世界视觉记录，表现寿命取该动画 16 帧 / 24 FPS，不改变真实伤害、冷却或触发次数。
