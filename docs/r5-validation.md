# r5 战斗机制、统计与 Excel 配置验证

日期：2026-10-29（北京时间）。目标版本：`v0.1.1-r5`，模拟修订：`arena-2026-10-29-r5`。

## 本版本内容

- 三份 Excel 维护技能、单位及商店/经济平衡。主技能按 1/2/3/6/9 点成行；4/5、7/8 分别使用前一有效档，授予子技能使用独立原生等级。公共属性、十列数字主参数、扩展参数和来源说明齐全。
- 手动编译、全量输入校验和规范化内容 hash；开发、构建、CI 只读检查编译一致性。游戏和战斗签名覆盖配置，旧的不兼容存档保留备份。素材导入不能覆盖维护中的 Excel 平衡值。
- 普通移动、恐惧、碰撞恢复和技能持续位移经过统一运动管线；明确技能空间跳变保留 warp 标记。单位按可配置转身速率面对目标后行动。
- 前摇、后摇、攻击点、弹速及距离缓冲独立配置；前摇中断不扣资源，后摇可由允许的新行动取消且不重置已释放攻击的间隔。
- 渲染插值相邻模拟帧，朝向走最短弧，真实瞬移跳过插值。展示坐标不参与命中、路径、随机或胜负。
- 攻击/法术分类与统计技能 ID 分离，独立闪避/抗性乘法叠加，多个暴击不连续相乘。反伤、溅射等保留各自增幅与吸血例外。
- 伤害、承伤、有效治疗和护盾吸收支持单位、技能、授予子技能和召唤物明细；父子汇总不重复计数。普攻含攻击加成/暴击，技能发起的攻击归该技能，独立附加伤害归其提供技能。
- 延迟结算保留技能、类型、归属及吸血来源；虚妄之诺按有效净结果分摊，保留非致死规则与原伤害顺序，避免重复减免或错误击杀归属。
- 列表与跳字使用物理米白、魔法蓝、纯粹金、治疗绿；暴击强调，高频持续伤害分类型聚合。手机可滚动展开技能明细，实时刷新保留位置及展开状态。

## 参考边界

保留 AA 明示数值、Super/Gaben 和四职业自定义。历史底层候选仍为 Valve 镜像 `6abdd9d13de2f4330ca748082467b9ff6e6cd928`，实际日期 2023-02-10；AA 快照补丁未被证明相同。现代 Wiki 用于研究和版本对照，不直接覆盖旧版技能。

四职业 18rad/s 匀速转身、11.5° 面向容差以及职业身体的工作参数可在表中调整；匀速模型不代表已恢复 Dota 原生加速曲线。概率触发继续使用显式 PRD 资格表，未取得对应 AA 证据的触发不擅自改为 PRD。

本版保持平面竞技场，不增加战争迷雾、日夜地图视野、树木或高低地；已有隐身、真视和不可侦测仍参与目标判断。环境依赖分支在报告中列为范围外。技能强制运动冲突和原生特殊优先级仍以逐项来源及工作规则为准。

屏障按来源使用显式工作策略：单位相位不穿技能墙；自由寻路穿沟壑/冰墙地形但受竞技场限制；飞行对这三类已知屏障有独立放行，未知技能墙仍阻挡。寻路、裁剪和连续脱困共用该策略。现代 Wiki 对特殊 path blocker 的措辞存在版本差异，因此此表不宣称全部历史例外已原作核验。

冰封路径原 AA 快照有两条同名 `DAMAGE`（0 与 50）。历史 Valve 通用 `AbilityDamage=0`（npc_abilities.txt:19769），实际 `AbilityValues.damage=50`（19791–19794），与历史 Wiki 的 Ice Path 50 伤害一致。本版明确修正旧读取首个0的行为，统一一个50伤害参数，并保留来源冲突记录。

230 主技能和 69 授予技能的可执行程序、配置及测试，不等于已完成全部技能所有组合的原作终验。逐项来源缺口和剩余边界保留在 `dist/data/mechanics-coverage.json` 与 `references/dota-wiki/r5-mechanics.json`。手机自动化视口检查不冒充实体设备性能验收。

Excel 使用说明见 [configuration.md](configuration.md)。配置 hash、ZIP SHA-256、CRC 与发布提交以本版 `release-report.json` 为准。
