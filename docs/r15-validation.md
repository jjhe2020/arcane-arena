# r15 技能平衡验证

## 调整口径

- 使用 r14 第 15 回合基线，随机种子为 `20261105`，共 100,000 对镜像阵容、200,000 场战斗。按胜场除以参战场次分别给 3、6、9 点技能排序，平局计入参战场次。
- 每档有 230 个技能。第 1～23 名削弱，第 208～230 名增强，六个截点均无并列。共调整 91 个技能的 138 个等级组合，每档削弱和增强各 23 项。
- 每个入选档位只改一个实际战斗参数，原值的相对改幅为 5%～12.5%。冷却和魔耗还检查了倒数对应的使用频率或资源效率。四处圆形范围增加后的几何面积增幅最高约 17.03%。这些上限约束配置和直接换算，实际胜率还取决于阵容、触发次数和对手。
- 3 点档适用于 3～5 点，6 点档适用于 6～8 点。完整的排名、胜场、场次、改动前后数值和理由见 [138 项调整清单](../config/reference/r15-balance-changes.json)。

| 档位 | 削弱示例 | 增强示例 |
| --- | --- | --- |
| 3 点 | 怒拳破脉冲伤害 150 → 135 | 黑洞每秒伤害 100 → 112 |
| 6 点 | 瘟疫守卫普攻伤害 100 → 90 | 死亡之指基础伤害 850 → 925 |
| 9 点 | 灼热之箭附加伤害 80 → 72 | 死神镰刀每点已损失生命伤害 0.90 → 0.98 |

## 验证与边界

- 将工作簿与 r14 对照，只变更技能等级表的 136 格和扩展参数表的 2 格。游戏和浏览器配置都只变更清单内的 138 个运行时数值及对应配置哈希。
- 25 对定向镜像阵容共 50 场战斗中，战斗引擎读取了全部 138 项新配置。
- 具名原作验收保留原有断言和参考数值。实战配置测试另外核对编译一致性、继承档位和实际战斗结果。
- 本地通过 `npm test` 的 4,102 项测试、`npm run reference:verify` 的 3,457 项测试、`npm run build`、生产资源校验、浏览器冒烟和实际战斗伤害账本检查。
- 距离审计实际探测 1,395 条可玩等级记录，配置接线审计通过。
- 基线使用固定模型优先级和随机阵容，排除了神、附魔与商店经济。榜单用于选择调节目标，完整的新版胜率仍需重新大规模抽样。
- 本次改动影响战斗重放，已递增模拟修订。旧模拟版本存档会走备份恢复入口，录像按模拟签名检查。
