# v0.1.1-r10：战场视角、平滑入场与布局修复

本开发版本修复左下角控制区与操作提示超框，并调整战场展示、入场和胜利动作。保留既有技能、经济、等级与原作机制验收边界，不代表全量终验完成。

## 本次行为

- 左侧暂停、倍速、对局菜单及操作提示紧跟八人排名，不再被排名区空白挤到面板底部。移除提示区固定高度；矮屏排名可滚动，控制按钮保持可达。
- 对战开始时，当前观战对象从下半场入场；观看同一场 A/B 任一方，都使用该方在下的视角。人物、特效、血条、伤害文字与点击拾取使用统一变换，切换视角不改战斗坐标、事件、胜负或重放数据。
- 布阵模式将所有不可放置区域变暗，可放置范围为 `x∈[-10.88,10.88]，y∈[-9.6,0]`。点击、拖动与暗区边界一致，合法阵位开战时不再被出生夹取移动。
- 布阵与观战的镜头用约 0.65 秒平滑切换。开始一轮时依次扩大镜头、移除暗区、淡入敌方，常规入场约 1.2 秒；所需身体图集未就绪时停在敌方淡入前，继续加载与重试，图集就绪并完成淡入后才推进所有战斗。普通模式或观战对象切换不暂停正在运行的战斗。
- 存活胜者循环播放庆祝动作，使用独立显示时钟，不受战斗结算时间停止影响；刷新结算存档后继续显示战场与庆祝。
- 地图逻辑宽高缩为原来的 80%，约 `23.3143×20.6667`。默认阵型、镜头、网格、碰撞与障碍边界、存档校验统一使用共享几何定义。英雄和特效保持原世界尺寸，相对地图放大约 25%，不额外叠加倍率。
- 射手射程为 7，法师为 5.5。只读核对单位 Excel 后确认源配置已符合这两个值，未更改工作簿或配置 hash；其它技能范围、速度与伤害保留原值。

模拟修订：`arena-2026-10-30-battle-presentation-r10`。地图几何会改变战斗重放，旧模拟签名不兼容的存档按既有恢复流程保留备份并提示新开对局。

- `npm run build`：配置一致性、机制报告、TypeScript 和生产构建通过。
- 构建后启动 `node scripts/serve.mjs`，生产资源检查通过：2974 个图像引用、1330 个移动图集，源码与构建配置一致。
- 生产浏览器冒烟、技能统计 UI 与真实引擎、商店与等级、8 项 UI 完整性、损坏存档恢复及淘汰后观战专项通过。

本版本汇总见 [r10 验证记录](../artifacts/r10-validation.json)。新增侧栏、战场展示与观战专项已纳入 GitHub Release 工作流。

## 验证边界

浏览器使用 Chromium 自动化与横屏触摸模拟，不替代实体手机性能与手感验证。入场资源等待只覆盖实际需要显示的身体图集，不预加载整局全部技能图集；常规纹理缓存及失败重试仍沿用既有机制。

逐技能机制继续沿用现有来源验收状态：230 项已开始审查，整项达到来源验收的为 7 项；3453 条技能要求中 834 条仍开放，189 条共用要求中 52 条仍开放。本次改动未扩大全量原作还原的完成声明。
