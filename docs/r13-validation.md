# v0.1.1-r13：单位检查、Buff、战斗录像与范围校准

本开发版本增加全阵营单位检查、状态图标、轻量战斗录像和高屏平板布局，扩展 Excel 调参，并核对全部技能档位的范围输入与呈现。范围审计与逐项机制还原分别记录，本版不宣称全量原作机制终验完成。

## 使用方式与行为

- 战场可点选己方、敌方、召唤物及幻象；右侧显示所选单位的实时属性、技能、归属和状态。检查敌方不切换棋盘，编辑入口只操作己方阵容。
- 血条上方显示一排来源技能小图标，正面绿框、负面红框；图标与层数限制在血条宽度内，超出不显示。计时边框随模拟时间擦除，暂停和倍速一致。永久效果保持完整边框，详情区显示全部状态，支持鼠标、键盘与触屏查看说明。
- 布阵详情与战场可见已实现的永久成长。技能收益跟随实例移动与合并；出售原技能后不会发给重购实例。英雄级永久属性增加来源账本，无法确定历史来源的数值只列历史汇总。
- “上轮战报”可下载当前战斗的 JSON 录像；“对局”中可下载或播放所有已归档战报。菜单提供“导入录像”和录像存储清理入口。缺少开局输入的旧战报无法补录。
- 录像包含冻结的双方开局、站位、技能及永久收益、种子、回合、输入日志、版本与配置指纹、终点与预期结算。回放独立于当前局，支持暂停、1/2/4倍速、从头播放和时间定位；退出后返回原局，不写回经济和战斗结算。录像结束显示确定性校验结果。
- 录像单独保存到本机 IndexedDB，开启新局不自动清除历史；写入失败仍保留当前会话的下载能力。JSON 不是视频，也不包含旧版引擎；版本或机械配置不匹配时提示所需 Release，不使用新规则强行重演。
- 高度充足且宽高比适合的布阵视口使用六列两排商店，十二个位置和购买顺序保留；小屏文字按空间缩放，长说明换行。依据视口判断，不识别具体 iPad 型号。

## 配置与范围

新增 `config/全局配置.xlsx`，包含战斗规则、棋盘布阵、AI策略和界面表现；技能表增加状态资料及补充机制参数。修改后继续手动执行 `npm run config:compile`。结构容量、固定步长、RNG、结算顺序与安全限制保留代码；每项数值只有一个维护来源。参见[配置说明](configuration.md)与[数值盘点](configuration-inventory.md)。

完整配置 hash 用于产物一致性，机械 hash 用于存档与录像兼容；修改纯展示文本或界面参数不使机械录像失效，仍被引擎或 AI 读取的内容保留在机械指纹中。

范围以用户自定义与 AA 历史规则为准，保留 Super/Gaben 明确强化。全量审计覆盖 230 主技能、109 可执行授予技能的所有档位，18 个参考技能单列，记录最终程序位置、配置、来源、实际运行与可见范围。当前 Valve 数据另作带取得时间及 hash 的对照，不覆盖历史规则，也不猜测当前补丁号。

等离子场的碰撞与主波纹共用起始偏移、环宽及当次半径，保留基础 700／升级 1100 扩展距离；区域特效使用实际半径，避免固定素材尺寸覆盖配置。主效果边界与合理装饰光晕分别处理。范围增益、动态攻击距离、实际区域与边界测试见[范围审计](r13-range-audit.md)。

## 版本与兼容

发布修订为 `r13`，模拟修订为 `arena-2026-10-31-status-replay-range-r13`。本次新增机械配置指纹和收益来源记录，旧存档不直接用新规则恢复；原存档保留备份，可导出后开启新局。已有 PWA 更新仍等待用户应用，不强制刷新正在运行的旧页面。

## 验证边界

- 全量档位运行、配置一致性、范围契约检查不等同于所有组合和所有原作边界均已认证。历史来源冲突、未恢复的 AA 特殊规则在逐技能报告中保留。
- 当前原作机制验收沿用既有要求记录；本版范围工作不会把未决机制标记为通过。
- 浏览器自动化包括 Chromium 桌面及平板触摸模拟，不替代实体 iPad／Safari 的系统安装、文件下载与性能验证。
- 录像存储属于当前浏览器和来源；用户清理网站数据或系统回收存储可能使归档不可用。需要长期保留的对局应下载 JSON 文件。
