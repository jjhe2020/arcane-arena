## 模块与当前协作边界

- `src/model.ts`：共享模型。
- `src/game.ts`：经济、阵容、AI、赛程、游戏存档。
- `src/combat.ts`：固定步长、状态/伤害/施法/弹道/区域/召唤及战斗恢复。
- `src/skill-effects.ts`、`skill-effects-extra.ts`、`skill-effects-more.ts`：显式按技能ID注册的机制与未实现清单。
- `src/main.ts`、`src/renderer.ts`、`src/game-ui.css`：主流程与交互、Three.js动画、跨端适配。
- `scripts/import-assets.py`：只读美术来源，生成运行派生资源与来源指纹。

开发服务默认`http://localhost:5173`；`npm run build`生成`dist`；`node scripts/serve.mjs`在4173启动构建；双击`启动游戏.cmd`启动并打开构建后的游戏。

目标保持active，以上缺口解决并取得与范围匹配的验证证据后再进行完成审查。
