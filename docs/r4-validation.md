# r4 可玩开发构建验证

日期：2026-10-29（北京时间）。运行修订：`arena-2026-10-29-r4`。

本包可运行1玩家与7个持久AI的完整比赛，支持三档金币倍率、淘汰排名、存档和恢复。每局抽取100项技能；五级商店分别开放4/6/6/8/10商品，三级起有终极技能，最后两格God禁用占位。

## 已通过的检查

- TypeScript、生产构建与28个测试文件共430项测试通过，含三种难度的完整8方比赛。
- 修正动作时钟、指定攻击触发的独立PRD、月刃攻击快照及串行弹射、骷髅逐击浮动、Empower前向范围、Jingu继承，以及无敌斩有效攻速和无目标提前终止。
- 实际状态决定护盾、狂暴、龙毒与寒霜、永久层数、熊形和远古召唤物外观；子技能自身等级与父级素材档次分开，移除原技能槽后已放出的效果仍保留视觉来源。
- 波环、随机爆点、移动弹道、引导连线、缚魂、传送门、冰柱及被动反击读取实际模拟元数据。波环的图集透明像素半径已测量，避免动画自身膨胀与世界缩放重复。
- 决斗边界与隔离只读有效双方状态，不增加碰撞；挑战、胜利和墨涌爆炸来自真实成功事件。近战旋风斧使用原有区域的时钟与位置。
- 生产浏览器购物、移动费用、战斗快照/下轮计划隔离、暂停、刷新恢复、4:3/16:9/21:9及手机横屏通过。
- 存储读写被拒、损坏战斗数量/种子/参与者、授予技能详情与真实冷却、观战对象连续淘汰和素材临时失败恢复均通过。
- 原生触摸检查覆盖第10个商品、两格God禁用、5名英雄共20槽、购买/分配保持滚动位置及全屏观战。667×275短视口保留关键操作。
- 2899个运行图片引用均存在，包含8个职业外观和1330个移动图集，生产数据与输入一致。

## 验证边界

- 230项基础/Super/Gaben均有工作分支，另有69个附属定义；机制报告仍全部标为`partial`，严格原作逐项验证为0。历史参数、PRD资格、目标与继承白名单等仍有工作默认和原作对照项。
- 16组专项桌面/手机模拟场景通过实际ID、图集、坐标、生命周期及渲染不修改快照的检查；场景使用明确记录的HP、法力和控制测试条件，不代表每个图层已完成逐帧终验。
- 最后5个专项快照进一步确认决斗装饰与隔离、墨涌触须/爆发，以及手机全屏近战旋风斧；未出现页面、请求、素材或WebGL上下文错误。
- 密集场景达到122个存活单位、409个绘制调用，移动视口活跃图片约100MiB。环境是Windows无头Chromium，不能当作手机真机帧率证据。
- 泥土傀儡和碎片临时复用已批准石质召唤物序列帧，尺寸有区分；这不是其专用造型。其它逐项边界见同目录`r4-visual-binding-gaps.md`与`dist/data/mechanics-coverage.json`。
- 图片按需加载，压缩包大小不代表开局下载量。仍需Node.js启动本地服务；本浏览器旧的不兼容存档会保留备份，可从菜单导出。
