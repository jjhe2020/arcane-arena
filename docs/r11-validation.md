# v0.1.1-r11：PWA 离线游玩与移动端全屏

本开发版本加入可安装的 PWA、完整资源离线下载和保留完整界面的原生全屏。逐技能还原的验收边界沿用既有记录，不代表全量终验完成。

## 本次行为

- 新增应用清单、192/512 图标、maskable 图标、Apple 主屏幕图标与安装引导。安装后优先使用横屏全屏显示，系统不支持时回退独立窗口。
- 桌面工具栏、手机横屏、纯净观战与竖屏提示均可打开“离线”面板。首次只缓存启动所需文件；用户点击下载后缓存全部角色、技能、场景、桌面及移动端图集，约 553 MB。下载有进度、资源数、空间用量与 Wi-Fi 提示。
- 资源逐项核对 SHA-256 与字节数；失败、版本不符或空间不足不会显示离线就绪。重试复用已经完成的文件；每次检查就绪状态都会核对实际缓存资源，资源被回收后可以补齐。离线就绪后支持断网冷启动、恢复存档和新开对局。
- 新版 Service Worker 等待用户点击更新或旧页面全部关闭后生效，避免自动刷新正在玩的对局。激活时清理旧的大型资源缓存，保留旧的不可变脚本块供尚未关闭的页面使用；新版本需要重新完成资源下载。其它网站缓存及本机存档不清理。
- 全屏按钮使用整个文档的 Fullscreen API，保留商店、阵容、排名和对话框；同步进入/退出状态，可选横屏锁定，兼容 WebKit 前缀。原“全屏观战”更名“纯净观战”，其收起界面的行为保持独立。
- 支持 viewport-fit、安全区与动态视口高度。初次竖屏进入时，即使对局菜单已打开，旋转提示中的全屏与离线入口仍可点击。浏览器拒绝或不支持全屏时提供安装到主屏幕的说明。

发布修订使用 `package.json` 的 `releaseRevision: r11`，模拟修订仍为 `arena-2026-10-30-battle-presentation-r10`。本次不更改战斗、经济或重放，兼容已有存档；发布校验及 ZIP 报告分别记录发布修订与模拟修订。

## 验证边界与使用条件

手机 PWA 安装和离线缓存需要 HTTPS 网站；电脑 localhost 也支持。通过普通 HTTP 局域网 IP 访问只支持联网游戏，面板会给出原因。Release ZIP 包含可部署的生产文件；本次没有新增公网托管网站。

自动化使用 Chromium 桌面、横屏触摸模拟及模拟 iPhone 用户代理的降级流程，不替代 Android/iOS 实体设备的系统安装与全屏验证。iPhone / iPad 建议先从 Safari 添加到主屏幕，再在应用中下载；浏览器与安装后的应用可能使用不同存储。系统是否隐藏全部系统栏、是否允许锁定方向由设备决定。

完整离线包包含全部图集，需约 553 MB 下载量及额外缓存空间；浏览器可能因设备空间紧张回收缓存。应用会检查资源是否齐全，但无法保证系统永不回收。清理网站数据会删除资源与存档。升级时建议结束其它打开的旧版本页面。

逐技能机制仍为 230 项已开始审查、7 项整项通过来源验收；3453 条技能要求中 834 条开放，189 条共用要求中 52 条开放。本次未扩大原作还原完成声明。
