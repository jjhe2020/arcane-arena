## 实际修复与规则限度

- **Sidekick / Spirit Link**：成对增益使用实际伙伴标记；生命目标吸血资格由提供者声明，不改变其它旧吸血提供者。Gaben 伙伴恢复的名义/有效/过量分摊仍为具名工作解释。幽魂链接按有效、可为负的护甲排除该来源自身贡献后共享，避免循环放大；原 AA 多召唤物聚合与偷技细节继续限定。原生熊形态使用 225 近战射程与独立 1–3 级，不再把 9 点 AA 测试夹具当成原生等级。
- **Soul Rip / Crimson**：符合资格的供体通过非致死 SetHealth 扣血，不制造伤害、承伤、治疗或虚妄之诺债务。名义供体数与扣血裁剪分开；特殊墓碑修复不冒称普通治疗。赤红甲为真实原生物品主动槽，初始化属性、被动 PRD 格挡、主动保证格挡、受益者类别和再次受益锁分开。主动已成功施加的保护可按自己的期限留存，初始化属性和被动仍随偷技源移除；这项兼容回归不是完整 Rubick 原作继承认证。
- **Shadow Wave / Juju**：伤害先于治疗；每次实际受 Dazzle 效果影响可独立增加邪能层数。贴近两个治疗点的敌人可被两次波及；邪能主动自身再增加一次影响，不递归无限加层。按历史 LinkedAbility 提供完整原生三级 Good/Bad Juju，Good 仅建模无神杖时的被动部分。熊形态、邪能及缠绕的终极类型均按原始 AbilityType 核对，不能凭三级或 effect-only 名称推断。
- **Spirit Siphon**：独立链接、四分之一秒结算与完整名义恢复、驱散后的施法者分量、距离缓冲和恐惧时钟分开。充能通过真实施法次数、不同目标和顺序恢复验证，不依赖旧私有字段名称。特殊反射、初始容量、源替换与实时射程等边界逐项记录。
- **Snowball / Waveform**：以真正连续运动段结算范围命中，回调发生在位置记录后、结束通知前；零段不重复结算。雪球施法者与乘客控制资格不同，乘客隐藏/保护与到达清理分开，Soulbind 显式只影响主目标。波浪允许普通转向、攻击和施法，先魔法伤害再触发 Gaben 攻击，保留 2023 天赋完整修饰、非必中及攻击穿免疫的语义，不倒灌现代 facet。地形豁免只对具名地形墙开放，不泛化未知技能屏障。
- **Torrent / Split Earth / Wild Axes**：冻结释放点并保留已释放效果；洪流逐包、浮空、减速和风暴子技能有独立时钟。撕裂大地先控制后伤害、重复点与独立闪电风暴等级分开。野性之斧先施加自身易伤再造成当前命中，声明的源限定易伤与通用承伤加法组结合；未声明的旧来源保持原乘区。旧神杖的零冷却仍须等斧头返回；AA 是否有意删除这一非数值限制缺乏原 Lua 证据，不能把强制并行绿色用例当成原作通过。
- **Tag Team / Vengeance / Warcry / Warpath / Goo**：摔角附伤回到同一主攻击包，参与暴击、格挡、攻击吸血和分裂；先减速再伤害，幻象仅触发减速。明确的半秒光环租期可以通过窄接触钩子在来源死亡后完成，其他死后钩子不放行。复仇强幻象的主动释放本来已有效，未伪报为从无到有；补齐具体来源、驱散和初始化边界。战吼先给受益者护甲，再计算既有 Gaben 攻击快照；动态与快照争议保持来源限制。战意每层独立到期、满层只刷新最老层；鼻涕采用真实弹道和统一受抗性截止时间，单体不可选与无目标范围资格分开。

## 共用修复

黑洞的旧拉拽包装器在伤害和控制被无敌拒绝后仍会施加高优先级运动，导致已滚动的雪球提前解体。现于建立效果和拉拽之前排除无敌、放逐及真实隐藏身体，保留普通隐形范围资格；没有增加所有技能共用的强制运动免疫。

面板魔抗改用与实际结算相同的有效修饰筛选，修正 Break 已压制 Demolish 而面板仍显示增益的问题。共享只读护甲查询同样不修改状态。显式格挡组仅对加入的原生提供者执行降序、同值保证优先、成功后停止试验；旧未分组格挡及其它完整原生组合不据此放行。

## 修正上一检查点的审查错误

C12 的 Hairball 边界曾将独立鼻涕技能错标为目录外。实际 230 项目录包含 `custom_bristleback_viscous_nasal_goo`；本批纠正程序说明、来源解释和未闭合条目，补真正学习该技能时的发球分支。原始历史响应与 SHA 不变。鼻涕有独立 700 范围，保留原毛团弹体和刺针回调；免费单目标子效果不再次展开未证实的 Super/Gaben 全范围行为。

完整 AA 字段审查又纠正两项明确差异：鼻涕的“取消前摇、提高施法距离”保留原有零前摇与 700 距离，未被原生 0.3 秒/650 覆盖；刺针扫射按 AA 明文即使没有敌人在范围内也会冷却就绪即施放，移除 C12 错误的近敌门槛。真实空范围两次施法不会制造伤害。89 项非空 AA differences 已另建只读索引供后续逐条审查，没有据索引自动声称全部差异通过。
