# v0.1.1-r9：商店识别、暂存购买与回合等级

本开发版本包含 r7 源码检查点 `f98cbd9b600dd074c2082b8329495dd44682e01f` 的六项补充需求及用户确认的 1A、2C，并修复云端慢速渲染环境暴露的单位面板重复重建问题。r7 云端 UI 完整性检查未通过，未产生 Release；其已推送 tag 保留，本次使用新 r9 tag。r8 云端全仓、来源验证与构建通过，但旧冒烟在战斗运行期间比较可变技能数组而失败；r9 固定测试种子，并先冻结全部战斗再比较，保留 r8 tag。保留 AA 数值、Super/Gaben、四职业、平面竞技场和已确认自定义。

## 浏览器验收时序修正

独立复核确认：备战玩家、战斗输入和运行技能均有深拷贝，技能移动只修改下轮玩家。旧冒烟在多个异步点击期间让战斗继续运行，正常召唤与授予技能都可能改变完整数组，不能据此推断编辑污染。现在先等待真实未结束战斗推进到至少 0.5 秒，再暂停；一次读取全部战斗时间、单位 ID 与技能，编辑前后及等待 350ms 后都必须完全一致。新局种子固定为 743，便于复现。

移动端长按用真实触点保持至详情弹窗出现，再松手，避免慢主线程把固定 600ms 截止误当作输入失败。保留不误购、金币及库存不变的断言。其它五份浏览器脚本已做同类时序只读复核。

## 面板交互修复

单位面板显示内容不变时保留现有 DOM 和滚动位置，暂停后不再每 300ms 销毁并重建技能和职业按钮。内容变化、单位变化及从统计页返回仍会正常更新。4 倍 CPU 限速下，暂停控件跨至少 750ms 保持同一节点，职业更换与授予技能详情仍通过真实点击打开。未暂停且生命/冷却等内容变化时仍可能重建面板，本次不宣称所有实时节点永久稳定。

旧 r7 生产包与本次开发源码使用相同增强断言做 before/after，旧包在两例稳定性断言失败，修复后通过。实际结果见 r8 验证汇总。

## 本次行为

- 商店移除右上角 i 按钮，保留右键及移动端长按说明。触摸长按与鼠标悬停使用独立计时器，避免混合输入设备取消长按。
- 全部 75 个已登记大招图标生成独立 SVG 资源，其中 62 个为主技能、13 个为授予技能。原始图像像素嵌入不变，紫金边框位于图标内部；商店、技能槽、图鉴共用同一资产。
- 商店对自己已装备或暂存的同名技能显示黄色外框。观战他人时仍按自己的库存判断，出售最后一个实例后高亮消失。
- 新技能购买后先进入暂存；暂存满时原子拒购，不扣钱、不消耗商品或库存。同名技能按用户确认的 2C 原位自动升级，可绕过满暂存；保留原实例与永久奖励，9 点仍拒购。AI 同样先暂存，再通过免费合法装备操作整理构筑。
- 第 N 回合英雄为 N 级，后到场英雄直接使用当前等级。当前实战快照等级锁定，下轮布阵显示下轮等级。一级完整总值只包含一次基础属性，后续属性成长与永久奖励分别增加；真实幻象和职业克隆继承等级攻速，普通召唤物保持独立原生模板。
- AI 每轮金币倍率提供 1.0–2.5、每 0.1 一档的 16 个选择；新局、存档、界面共用同一有效档位集合。整局验证覆盖 1、1.5、2、2.5 四个代表档位。
